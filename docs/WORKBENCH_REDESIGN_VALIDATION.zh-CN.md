## 页面与功能去向

| 页面 | 当前结构与保留功能 |
| --- | --- |
| 运行概览 | 主指标与请求趋势、Provider 状态、异常排查旁区；完整时间筛选、Token 趋势、来源与估算说明、最近调用和接入检查保留在辅助展开区 |
| 请求日志 | 完整筛选、汇总、分页与虚拟请求队列；桌面常驻详情，窄屏返回列表；完整身份、路由、Token、费用、重试与证据字段保留；选中请求写入 URL，支持刷新与历史恢复 |
| 模型与渠道 | Provider 目录与选中对象事实；Provider 和模型适配内联编辑；模型库存、发现、测试、账号、别名、解析顺序及高级兼容配置继续使用原有操作 |
| 用户 | 用户目录、完整身份与统计、生命周期操作和用户编辑；关联密钥入口及一次性签发交接保留；完整列表收纳为横向比较 |
| API Keys | 密钥目录、身份/范围/策略/费用/轮换上下文；内联编辑，签发与轮换保留一次性受保护交接；原列表可展开 |
| 配额 | 规则目录和内联编辑；用户、类型、周期、用量、限额与重置语义保持，独立单位不相加；零限额确认及删除保留 |
| 运维中心 | 事件队列与证据、时间线和处理操作同屏；Agent 配置与汇总置于辅助区；配置草稿提供离开保护 |
| 企业账本 | 请求队列与完整事实、Attempts、租约和对账详情；预算、调整原因和证据操作保留在局部分区 |
| 治理审批 | 审批队列、变更载荷与审批/应用操作；提交表单与治理状态置于辅助区，提交草稿提供离开保护 |
| 系统设置 | 分类目录与配置事实阅读区；保持配置只读，原运维操作和危险操作确认不变 |
| 接入指南 | 步骤目录、当前任务与示例；真实可见模型、密钥与客户端协议示例保留，管理员步骤按角色显示 |
| 登录 / 404 | 独立构图与工作区返回入口；原认证能力、校验、错误及 SSO 条件保持 |

全局使用工作区导航和局部页面导航，网关进程状态与快速导航仍可访问。内联编辑、对象切换、工作区切换、浏览器后退和退出登录共用离开保护；一次性密钥继续调用既有确认交接逻辑。

## 验证

- Node 24.19.0：`npm --prefix dashboard run check` 通过，包含 TypeScript、零警告 ESLint、29 个测试文件 / 109 项单元测试及 Vite 生产构建。
- Playwright 全量 30 项回归通过：全路由浅色/深色、桌面与 390px、角色与直接路由拒绝、虚拟长日志、加载/错误/重试/空状态、Provider 管理、用户与密钥、设置热加载、账本及指南。
- 最后稳定共享离开保护回调后，6 项相关回归通过；新增“用户关联密钥交接 + 浏览器后退”单项验证通过。新增请求历史测试主动生成隔离失败请求，不依赖其他测试顺序。
- 全部 13 路由在 1440、1024、390px 共 39 张正式页面截图，页面溢出与运行时异常检查结果为空，见[截图检查记录](assets/workbench-redesign/implementation/capture-results.json)。另保留带“演示数据”标记的 mock 概览和日志详情截图。
- `git diff --check` 通过。正式入口不再加载原型组件。

复验需启动项目自己的隔离 E2E 后端并提供凭据文件，然后在 `dashboard/` 下运行：

```bash
ROUTEPILOT_ENV_FILE=/path/to/test.env PLAYWRIGHT_BASE_URL=http://127.0.0.1:33013 PLAYWRIGHT_SKIP_WEBSERVER=1 npm run e2e
ROUTEPILOT_ENV_FILE=/path/to/test.env PLAYWRIGHT_BASE_URL=http://127.0.0.1:33013 node scripts/capture-workbench.mjs
```

测试专用容器与凭据在验收后清理。本地演示地址为 `http://127.0.0.1:33012/dashboard`，mock 登录 `admin / admin`。
